# 📊 Sales Performance & Target Achievement Dashboard (Excel)

## 🔍 Project Overview
This project is an interactive **Sales Performance Dashboard** built in Microsoft Excel to track and analyze sales executives' performance across different regions.

The dashboard helps monitor:
- Total Sales
- Target Achievement %
- Away From Target %
- Regional performance comparison
- Top and low performers

It enables quick, data-driven decision-making for sales managers.

---

## 🎯 Objective
The goal of this project is to:
- Analyze sales performance by executive and region  
- Compare actual sales against targets  
- Identify high-performing and underperforming sales executives  
- Present insights using a clean and interactive dashboard  

---

## 🗂️ Dataset Description
The dataset includes:

- **Employee Code**
- **Sales Executive Name**
- **Region**
- **Daily Sales (Day 1–Day 5)**
- **Total Sales**
- **Sales Target**
- **Target Hit %**
- **Away From Target %**
